# サバイバルバトルX100

100人（自分＋CPU99人）が広大なフィールドに降り、宝箱を壊して武器を集め、最後の1人を目指すバトルロイヤル。
開始から5秒間は全員無敵。四隅には固有の特殊能力を持つボスが4体いる。
武器は **全500種**（基礎70種 × 7ランク = 490種 ＋ 特別武器10種）。

ブラウザだけで動く。ビルド不要、外部ライブラリなし、Canvas 2D のみ。

## 遊ぶ

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

`index.html` をダブルクリックしても動く。

## 操作

| 操作 | キー |
|---|---|
| 移動 | W A S D |
| 攻撃 | 左クリック（長押しで連射／チャージ） |
| サブ動作 | 右クリック または Shift |
| 武器切替 | Q ／ 数字キー |
| 緊急回避 | Space（前方へ跳ぶ・食料-10） |
| 拾う | E |
| 回復 / 食料 / ガードポーション | R / F / G |
| バリア纏い切替／属性切替 | X |
| 地図の拡大 | M |

スマホは画面左半分でスティック移動、右半分をタップで照準＋射撃（自動照準あり）。
右下に8個のボタン（回避・拾う・武器切替・特殊・回復・食料・防御・受け）が出る。ミニマップはタップで拡大。

## 実験モード

メニュー下部のパスワード欄から入る検証用モード。CPUなし・無敵・攻撃力10億のショットガン・武器スロット10個。
ゲーム中に **T** キー（スマホは「検索」ボタン）で全501種から武器を選んでストックに入れられる。
パスワードと詳細は `docs/SPEC.md` の第9章。

## ファイル構成

```
index.html              画面のマークアップ（メニュー・図鑑・リザルト）
css/style.css           全スタイル
js/game.js              ゲーム本体（素のJavaScript）
assets/weapons.png      武器アイコン80個を並べた画像（背景透過）
assets/source-*.png     アイコンの元画像
tools/sim.js            ヘッドレス検証ツール（ロジック）
tools/render-test.js    描画テスト
tools/stair-test.js     階段テスト
tools/extract-icons.py  元画像からアイコン画像を作り直す
docs/SPEC.md            仕様書。ルール・武器・キャラ・ボスの定義はここが正
docs/TODO.md            未実装・これから決めること
```

## 変更したら必ず実行する

```bash
node tools/sim.js 5          # ロジック：全500種の発射と5試合の自動対戦
node tools/render-test.js    # 描画：全500種を持たせた状態と9つの場面を描く
node tools/stair-test.js     # 階段：全部の階段を登り降りしてすり抜けを確認
```

どちらも例外が出るか、試合が決着しなければ終了コード1で落ちる。

## 現状の数値（tools/sim.js 実測）

- 平均試合時間: 6〜11分
- 1分後の生存者: 30〜50人
- CPUがボスを倒すことも稀にある（4体中0〜1体）
- 処理負荷: 実時間の約5%（100体＋弾＋ボスを同時に動かして余裕あり）
