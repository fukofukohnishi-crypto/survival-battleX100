# 仕様書

実装済みの内容と、そのルール。数値は `js/game.js` の定数と一致させること。

## 1. フィールド

- 178 × 178 タイル（1タイル32px、全体 5696 × 5696 px）
- タイル種別: `FLOOR(0) / WALL(1) / STAIR(2) / HIGH(3) / ROCK(4) / HOUSE(5)`
- **壁・岩・家の壁はすり抜けられない**（円形の当たり判定でX軸Y軸を分けて処理）
- **高低差**: エンティティは `lvl` を持つ（0=地上、1=高台）
  - `HIGH` タイルには `lvl===1` か、階段の上に乗っている時だけ入れる
  - `STAIR` は両方から入れる。階段から降りれば `lvl=0`、登れば `lvl=1` になる
  - **地上から撃った弾は高台のタイルで止まる**（＝高台が有利）。高台からは地上を撃ち下ろせる
  - 近接攻撃は同じ高さ、または72px以内なら段差越しでも当たる（睨み合い防止）

### 生成される物

| 物 | 数 | 内容 |
|---|---|---|
| 家 | 52軒 | 壁で囲まれ、ドアが1箇所。**必ず宝箱1〜3個**。50%の確率で階段付きの中二階 |
| 高台 | 38箇所 | 階段1〜3本。80%で宝箱1個（レアリティ補正1.4倍） |
| 岩 | 約700群 | 遮蔽物 |
| ボス闘技場 | 四隅4箇所 | 半径15タイルの円形。入口1箇所。**中央は平ら**（段差があると地上からの弾が届かない）。四隅に岩の遮蔽、斜めに宝箱2個（補正2.6倍） |
| 野良宝箱 | 330個 | フィールド各地にランダム |

生成順は「闘技場の場所を予約 → 家 → 高台 → 岩 → 闘技場を掘る → 野良宝箱」。
予約マスク `res` があるため家と高台は重ならない。

## 2. プレイヤー

- 100人（自分1人＋CPU99人）。開始時は16×16のマスに分散して配置され、事故死しない
- 武器スロットは2つ（実験モードのみ10）。埋まっている状態で拾うと、選択中の武器を地面に落として入れ替える
- スロット数は `e.wp` の配列長で決まる。**2個固定を前提にした書き方をしないこと**
- 弾薬は種類を分けず1つのプールで管理する（リロードなし）
- **開始から5秒間は無敵**（`inv`）。ダメージを受けても「無敵」と表示されるだけ
- 武器がない／弾切れなら**素手**（攻撃7・リーチ34・0.52秒）になる

|---|---|

| 防御力 | ガードポーションで+55、上限120。ダメージの55%を肩代わりして減っていく |
| 満腹度 | 100から毎秒0.42ずつ減少。**0になると毎秒1.6ダメージ＋移動速度45%減** |
| 弾薬 | 初期60（特殊部隊は300） |

### 全ボス共通

| 攻撃 | 内容 |
|---|---|
| 円形弾幕 | 2.4秒ごと（第2形態1.5秒）に12発（第2形態18発）。**体の外側から発射する**（中心から出すと自分に当たる） |
| 叩きつけ | 160px以内に敵がいると2秒ごとに半径150の範囲攻撃＋吹き飛ばし |
| **継続ダメージビーム** | 8秒ごと（第2形態5.2秒）。0.9秒の予告線のあと2.6秒（第2形態3.4秒）照射。**角度は予告が出た瞬間に決まり、以後1度も変わらない**。**向きは予告が出た瞬間に固定され、追尾は一切しない**。**当たっている間0.15秒ごとに9ダメージ**（第2形態13）＋軽い燃焼。壁で遮られる。**照射中はボスの位置も角度も完全に固定**され、弾幕も撃たない。**当たっている相手は横へ押し出される**ので、スタン中でも焼かれ続けることはない |

ビームの向きは**予告線が出た瞬間に決まり、そこから一切変わらない**（予告中も照射中も追尾しない）。
照射が始まればボスの位置も固定される。
つまり予告線の外へ動けば無効化でき、そのうえボスは棒立ちなので、**そこが最大の反撃機会**になる。
当たってしまった場合も、判定を受けるたびにビームの軸から**横へ押し出される**（0.15秒ごとに横向きの吹き飛ばし6）。
落雷のスタン中に照射されても、押し出しだけで抜けられる。

特殊能力は**必ず30秒に1回**。第2形態でも間隔は変わらない。

チャンスタイム中は金色の破線の輪と残り秒数が表示される。ここで一気に削るのが攻略の軸になる。

## 5.5 スポーン時の無敵

**開始から5秒間、100人全員とボス4体が無敵**。この間のダメージはすべて無効になり、
体の周りに水色のリングが点滅する。プレイヤーには画面中央に残り秒数が出る。

## 5.6 危険地帯（hazards）

炎の海のような「そこにいると継続的にダメージを受ける床」は `hazards` 配列で管理する。
`{x, y, r, l(残り時間), dmg, burn, o(発生させた者), c(色)}`。
0.2秒ごとに範囲内の全員に判定する。`updateHazards(dt)` をメインループから毎フレーム呼ぶこと。

## 7. CPUの思考

0.3〜0.7秒ごとに再判断する。

- **索敵範囲は時間で広がる**: `240 + 進行度×1700` px。3.5分経過で全域索敵になり、遠い敵には1.4倍速で突っ込む
- 敵が近くにいなければ900px以内の宝箱を壊しに行く
- 体力55%未満で回復、満腹度28未満で食事、防御12未満でポーションを使う
- 体力30%未満で回復がないと2.6秒だけ逃げる
- 近接なら密着、遠距離なら射程の45%を保って左右に回り込む
- 落ちている武器は、今の武器よりDPSが高ければ拾う（弾切れなら近接を優先）
- **1.4秒動けていないと迂回モード**に入り1.7秒だけ別方向へ。高台に閉じ込められた場合は最寄りの階段を目指す
- **残り6人以下になると経路探索を使う**（`pathStep`）。目標地点から幅優先探索をして次に進むマスを求め、
  1.2秒ごとに更新する。壁を挟んですれ違い続けて試合が終わらない事故を防ぐためのもので、
  平常時は負荷を避けるため使わない
- プレイヤーから1500px以上離れたCPUは弾を発生させず、確率判定で戦う（負荷対策）

## 9. 実験モード

メニュー下部のパスワード欄に **`monoshirikunn`** を入れると入れる検証用モード。
パスワードは `js/game.js` の `startGame` 付近に平文で書いてある。
ソースを読めば分かるので、**秘密を守る仕組みではなく、間違って入らないための鍵**という位置づけ。

| 項目 | 通常 | 実験モード |
|---|---|---|
| CPU | 99人 | **0人（自分だけ）** |
| ボス | 4体 | 4体（変わらず） |
| 自分 | 5秒だけ無敵 | **ずっと無敵**（`god` フラグ。空腹・燃焼・毒も無効） |
| 初期武器 | キャラの武器 | **実験用ショットガン**（攻撃力10億・散弾10発・弾薬不要・貫通4） |
| 武器スロット | 2 | **10**（数字キー1〜9と0で選択） |
| 所持品 | 少量 | 回復・食料・薬を各99、弾薬999999 |
| 勝利判定 | 残り1人で勝利 | **なし**（好きなだけ検証できる） |

実験用ショットガンは `SP.expgun` として `SPECIALS` の外に定義してある。
そのため**図鑑にも宝箱のドロップにも出てこない**。武器を500種と数えるときにも含めない。

実装は `expMode` フラグ1つで分岐している。`spawnAll` で装備と無敵を設定し、
`hurt` の先頭で `god` を弾き、`updateEnt` で体力と満腹度を戻している。

## 10. 落雷（strikes）

壁も段差も無視して当たる攻撃は、共通の `strikes` 配列で扱う。

```js
thunderStrike(x, y, 発生させた者, ダメージ, スタン秒, 予告の長さms, 半径, 割合)
```

予告円が縮んでいき、時間が来たら円の中の**全員・ボス・宝箱**に当たる。地形は一切参照しない。
最後の `割合` を渡すと、固定ダメージではなく**相手の最大体力に対する割合**で削る（雷霧の巨兵は 2/3）。
キャラクターごとに体力が違うため、割合で指定しないと相手によって脅威度が変わってしまう。
`updateStrikes(dt)` は `updateHazards(dt)` の先頭から呼ばれる。
使っているのは、雷霧の巨兵の能力／プラズマボトルレールガン／神槍の雷属性の3つ。
